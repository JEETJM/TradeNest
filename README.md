## 📌 About TradeNest

**TradeNest** is a full-stack stock trading platform inspired by modern online investment applications.

It provides users with a clean trading dashboard where they can manage:

- 📊 Portfolio
- 📈 Holdings
- 🧾 Orders
- 💰 Funds
- ⭐ Watchlist
- 📉 Analytics
- 👤 Profile
- ⚙️ Settings
- 🔐 Authentication
- 📡 Real-time market updates

The application is built using the **MERN stack** with additional technologies such as **JWT authentication, Socket.IO, Upstox market data and Cloudinary**.

## 📊 Trading Dashboard

TradeNest provides a complete dashboard containing:

- Portfolio summary
- Available balance
- Invested amount
- Current value
- Total profit/loss
- Holdings
- Orders
- Market insights
- Portfolio analytics

---

## 📈 Holdings

Users can view:

- Stock symbol
- Quantity
- Average price
- Current price
- Invested amount
- Current value
- Profit/Loss
- Profit/Loss percentage

The holdings section also updates using market data.
